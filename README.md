# 모코코 메이트

로스트아크 파티 모집과 서버 인증을 지원하는 Discord 봇입니다.

## 기능
- 아이템 레벨별 레이드 모집 패널
- 레이드 / 난이도 / 숙련도 / 최소 아이템 레벨 / 출발 시간 / 인원 / 메모 입력
- 모집 생성 시 @everyone 알림 및 전용 스레드 생성
- 딜러 / 서폿 참여, 취소, 인원 자동 갱신, 자동·수동 마감
- 모집 수정 및 봇 재시작 후 버튼 복구
- 인증 패널에서 캐릭터명 입력 및 로아 서버 선택
- 인증 완료 시 닉네임 변경, 인증 역할과 서버 역할 지급
- 신규 입장자에게 미인증 역할 자동 지급(설정 시)
- SQLite 저장

## 최초 설정
1. Discord Developer Portal에서 봇의 Server Members Intent를 켭니다.
2. .env에 DISCORD_TOKEN, GUILD_ID, DB_PATH를 설정하고 실행합니다.
3. 서버 관리자 권한으로 /인증역할설정에서 인증 완료 역할과 미인증 역할을 설정합니다. 미인증 역할은 선택 사항입니다.
4. /서버역할설정을 각 로아 서버마다 실행해 서버명과 지급 역할을 연결합니다.
5. 인증 전용 채널에 /인증패널을 생성합니다.
6. 구인 채널에 /모집패널을 생성합니다.

봇 역할은 지급할 역할들보다 위에 있어야 합니다. 인증 전용 채널은 미인증 멤버가 볼 수 있게 하고, 나머지 채널은 인증 완료 역할에 접근 권한을 주면 됩니다.

## 실행
```bash
python -m venv .venv
pip install -r requirements.txt
cp .env.example .env
python bot.py
```
